# BestShot downloads

Signed installers and automatic-update feeds for [BestShot](https://bestshot.site) — local-first screenshots, screen recording and meeting transcription.

- **Windows x64:** download the latest `BestShot_<version>_x64-setup.exe` from [Releases](https://github.com/StephenLovino/bestshot-releases/releases).
- **macOS Apple Silicon:** download the latest `BestShot_<version>_aarch64.dmg` from [Releases](https://github.com/StephenLovino/bestshot-releases/releases) (signed and notarized).

Installed apps update themselves from the `windows-updates` / `macos-updates` feeds in this repository. Updates are signature-verified by the app before installing.

This repository contains release files only.
